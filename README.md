A Progressive Web App (PWA) version of the classic Flappy Bird game with an underwater theme.

Features
🐠 Play as a fish navigating through pipes

🌊 Underwater theme with smooth animations

📊 Score tracking and high score saving

🔊 Sound effects and background music

📱 Fully responsive for mobile and desktop

⚡ PWA features:

Offline play capability

Installable on devices

Fast loading

How to Play
Tap/click or press spacebar to make the fish swim up

Navigate through the pipes without touching them

Try to get the highest score!

Live Demo
Play the game online:
https://iahjhe.github.io/Ambas-finalexam-fluffyfish/

Installation (PWA)
Open the game in Chrome or Edge

Click "Install" when prompted or:

Chrome/Edge: Click the install icon (📥) in the address bar

Safari: Tap "Share" then "Add to Home Screen"

Launch the app from your home screen
